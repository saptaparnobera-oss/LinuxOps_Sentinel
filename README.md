# LinuxOps Sentinel

A modular Linux system monitoring and security
toolkit built using Bash scripting.

## Features

- System Information
- Disk Usage Monitoring
- CPU and Disk Threshold Configuration
- Network Information
- Process Monitoring
- Suspicious Process Monitoring
- Failed Login Monitoring
- File Permission Monitoring
- Service Information and Failure Monitoring
- Package Information
- File Management System
- Automation Runner

## Technologies Used

- Kali Linux
- Bash Scripting
- Linux Command-Line Utilities
- Git and GitHub

## Project Structure

- linuxops.sh — Main menu
- automation_runner.sh — Automation runner
- config/ — Configuration files
- modules/ — Monitoring and management modules
- logs/ — Log files

## How to Run

```bash
chmod +x linuxops.sh
./linuxops.sh
